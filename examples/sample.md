# 操作系统：进程与线程

## 一、基本概念

进程是**资源分配的基本单位**，线程是*CPU 调度的基本单位*。同一进程内的线程共享地址空间，所以线程切换比进程切换开销小得多。

进程的组成：

- 程序段（代码）
- 数据段
- PCB（进程控制块）
  - 进程标识 PID
  - 处理机状态
  - 调度信息

> 记住：**PCB 是进程存在的唯一标志**，创建进程就是创建 PCB。

## 二、进程状态

1. 就绪：已具备运行条件，等待 CPU
2. 运行：正在使用 CPU
3. 阻塞：等待某事件，如 I/O 完成

### 常见调度算法

| 算法 | 特点 | 缺点 |
| --- | --- | --- |
| FCFS | 简单公平 | 对短作业不利 |
| SJF | 平均等待时间最短 | 可能导致~~饥饿~~ |
| RR | 响应快 | 时间片难选 |

## 三、代码示例

```c
pid_t pid = fork();
if (pid == 0) {
    execl("/bin/ls", "ls", NULL);
}
```

要点速记：

- `fork()` 返回两次
- 子进程返回 0，父进程返回子进程的 PID
- 用 `wait()` 回收，防止产生*僵尸进程*
