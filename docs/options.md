# 全部选项

本文件由 `python tools/gen_options.py` 从源码生成，不要手改。
在配置文件里写成 `[section]` 下的 `key = value`，或在命令行用 `--set section.key=value`（可重复）。
`handnote config` 打印当前全部取值；`examples/config.example.toml` 是带说明和候选值的完整配置文件（`handnote init-config` 可生成并自动生效）。
约定：数值型的效果设为 0 就是关闭；概率设为 0 是从不发生，设为 1 是必定发生。

## [page] 页面几何

单位是像素。默认 A4、200 dpi。文字基线落在 margin_top + n × pitch 这条网格上，横线纸的线画在同一网格上。

| 选项 | 默认值 | 候选 / 期望值 | 说明 |
|---|---|---|---|
| `width` | `1654` | 整数像素；A4@200dpi 为 1654，A5 为 1169（用纸张模板时模板会给出） | 页宽 |
| `height` | `2339` | 整数像素；A4@200dpi 为 2339，A5 为 1654 | 页高 |
| `margin_top` | `150` | 整数像素，100 ~ 200；决定第一行基线和横线的起点 | 上边距；也决定横线网格的起点 |
| `margin_bottom` | `130` | 整数像素，80 ~ 200 | 下边距 |
| `margin_left` | `170` | 整数像素，120 ~ 260 | 左边距 |
| `margin_right` | `100` | 整数像素，60 ~ 160 | 右边距 |
| `pitch` | `64` | 整数像素，52 ~ 72；越小一页越密，字号 = pitch × text.size_ratio | 行距，文字基线对齐到这个网格 |

## [llm] 本地模型（handnote write 用）

指向一个 OpenAI 兼容的服务，例如 llama.cpp 的 llama-server。提示词内置在程序里，这里只配连接和采样。

| 选项 | 默认值 | 候选 / 期望值 | 说明 |
|---|---|---|---|
| `host` | `127.0.0.1` | 主机名或 IP，如 "127.0.0.1"、"192.168.1.5" | 模型服务地址（llama-server 的 --host） |
| `port` | `8080` | 整数端口，llama-server 默认 8080 | 模型服务端口（llama-server 的 --port） |
| `base_url` | `""` | "" \| "http://主机:端口/v1"；填了就忽略 host 和 port | 完整的 OpenAI 兼容地址，如 http://192.168.1.5:8080/v1；留空则用 host 和 port |
| `model` | `qwen3.6-35b-a3b` | 模型名字符串，如 "qwen3.6-35b-a3b" | 请求里写的模型名（llama-server 单模型时基本忽略，多模型/代理时用来选模型） |
| `api_key` | `""` | "" \| 密钥字符串 | 服务要求鉴权时填；本机一般留空 |
| `temperature` | `0.6` | 0 ~ 1.2；0.4 ~ 0.8 比较稳 | 采样温度，越低越稳 |
| `top_p` | `0.95` | 0.8 ~ 1.0 | 核采样 |
| `max_tokens` | `4096` | 整数，2048 ~ 8192；两页笔记约 1500 token | 一次最多生成多少 token |
| `thinking` | `False` | true \| false | 是否让模型先思考再写（Qwen3 一类；关闭更快，笔记不需要长推理） |
| `timeout` | `900` | 整数秒，120 ~ 1800 | 单次请求最长等待秒数（本地大模型首个字可能要等很久） |
| `fix_rounds` | `3` | 整数 0 ~ 5；0 为检查出问题也不让模型改 | 检查不通过时最多让模型改几轮；0 为不改 |
| `notes_dir` | `notes` | 目录路径，如 "notes" | 生成的笔记 .md 存放目录 |
| `chunk_chars` | `9000` | 整数，3000 ~ 30000；模型上下文越大可以越大 | 课件文字超过这么多字时，先分段让模型提炼要点，再用要点写笔记（按模型上下文大小调） |
